# 웹소설 문장 · 문단 유사도 검사

웹소설 원고 두 개 사이에서, 또는 원고 하나 안에서 같거나 조금 고친 문장을 찾아 주는 웹 도구입니다.

**바로 쓰기: https://jhste102lab.github.io/web-novel-similarity/**

- 파일은 서버에 저장하지 않고 사용자의 브라우저에서만 처리됩니다. 서버, 로그인, 저장 기능이 없습니다.
- 입력: `.txt`, `.docx`, `.hwpx`. (`.hwp`는 한글에서 `.hwpx`로 다시 저장해 주세요.)
- 결과: 겹치는 회차 쌍 목록과 A/B 대조, 등급(거의 동일 · 일부 수정), PDF/PNG 내보내기. 흔한 표현이나 약한 유사는 아예 보여주지 않습니다.
- 검사 중에도 찾은 결과부터 바로 보여 줍니다. 중단하면 그때까지 검사한 결과가 남습니다.
- 키보드: `j`/`k` 이동, `/` 찾기, `c` 복사, `d` 진단(단계별 시간 · 실제 비교한 문장쌍 비율), `?` 단축키 목록.
- 한 번 연 뒤에는 인터넷을 끊어도 동작합니다. 서버에 아무것도 보내지 않는다는 뜻입니다.
- PC · 태블릿 기준. 모바일은 고려하지 않습니다.

실제 원고는 데이터셋으로 배포하지 않습니다. 공개 저장소에는 직접 작성한
합성 벤치마크만 포함합니다. 실제 원고로 검증하더라도 원문·제목·파일명·해시
등은 커밋하지 않고, 익명 합계와 조정된 기준값만 남깁니다.

## 실행

Node 24 이상.

```sh
npm install
npm run dev     # 개발 서버
npm run build   # 정적 빌드 (dist/)
npm test        # 단위 테스트
```

원고 파일 두 개를 명령줄에서 바로 비교할 수도 있습니다.

```sh
node scripts/compare.ts A.txt B.txt   # A/B 비교
node scripts/compare.ts A.txt         # 원고 하나 안의 반복
```

`main`에 푸시하면 GitHub Actions가 lint · test · build 후 GitHub Pages에 배포합니다.

## 어떻게 찾나요

1. 원고를 문장으로 나누고, 문장마다 글자 5개 단위 지문(winnowing)을 뽑습니다.
2. 지문을 공유하는 문장 쌍만 후보로 골라, 편집 거리로 얼마나 같은지 잽니다.
   200만 자 × 200만 자 원고에서 가능한 문장 쌍의 0.01%만 실제로 비교합니다.
3. 이어지는 유사 문장을 구간으로 묶고, 회차 쌍별로 정리해 등급을 붙입니다.

기준값은 직접 만든 합성 원고 벤치마크로 정했습니다(`bench/`, `docs/plan/2026-09-21-benchmark.md`).
